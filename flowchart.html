sequenceDiagram actor 사용자 participant FE as Frontend participant Auth as Auth Service participant CS as Customer Service participant IS as Inventory Service participant BS as Booking Service participant PS as Payment Service 사용자->>FE: 항공편 선택 FE->>Auth: 로그인 상태 확인 alt 비로그인 Auth-->>FE: 인증 필요 FE-->>사용자: 로그인 요청 사용자->>FE: 로그인 FE->>Auth: 인증 처리 Auth-->>FE: 토큰 발급 end FE->>IS: 좌석 홀드 요청 IS-->>FE: 홀드 성공 (TTL: 15분) 사용자->>FE: 탑승자 정보 입력 FE->>CS: 승객 정보 저장/조회 CS-->>FE: 승객 정보 반환 사용자->>FE: 결제 요청 FE->>PS: PG 결제 요청 alt 결제 실패 PS-->>FE: 실패 응답 FE-->>사용자: 오류 안내 / 재시도 else 결제 성공 PS-->>FE: 승인 완료 FE->>BS: PNR 생성 요청 (탑승자+여정+요금 스냅샷) BS->>IS: 좌석 홀드 → 확정 IS-->>BS: 확정 완료 BS-->>FE: PNR 반환 FE-->>사용자: 예약 완료 end
