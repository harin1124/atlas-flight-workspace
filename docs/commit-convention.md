# 커밋 메시지 컨벤션

워크스페이스 메타 레포와 하위 모든 모듈(`atlas-flight-*`)에 공통으로 적용한다.

## 1. 기본 형식

```
type(scope): 한글 명사형 제목

- 변경 항목 1
- 변경 항목 2
```

| 항목 | 규칙 |
|------|------|
| 제목 | `type: 내용` 또는 `type(scope): 내용`. 내용은 한글 **명사형**으로 끝낸다 (`~추가`, `~변경`, `~수정`, `~정정`) |
| scope | 선택. 모듈·도메인을 좁힐 때만 붙인다 (`auth`, `customer`, `my-page`, `passenger` 등) |
| 제목 끝 | 마침표를 찍지 않는다 |
| 본문 | `- ` 목록으로 쓰고, 각 항목도 명사형으로 끝낸다. "~한다." 같은 서술형 문장은 쓰지 않는다 |
| 짧은 커밋 | 변경이 하나면 본문 한 줄(예: `컨테이너 명칭 변경`)이나 제목만으로 충분하다 |
| 식별자 | 파일명·클래스명·경로·설정 키는 원문 그대로 쓴다 |

---

## 2. type

자주 쓰는 `feat`, `fix`, `refactor`, `chore`가 위에 있고, 나머지는 해당할 때 쓴다.

| type | 용도 | 이 프로젝트 예시 |
|---|---|---|
| `feat` | 새 기능 추가 | 내 정보 조회 엔드포인트 추가 |
| `fix` | 버그 수정 | 관계 코드 컬럼 매핑 정정 |
| `refactor` | 동작 변화 없이 구조 개선 | MariaDB driver 변경 |
| `chore` | 그 밖의 잡무 (스크립트, 툴링 등) | sync.sh 수정 |
| `perf` | 성능 개선 | 쿼리 N+1 제거 |
| `style` | 포맷·공백·세미콜론 등 (로직 변화 없음) | lint 자동 정리 |
| `docs` | 문서만 변경 | `docs/*.md`, README 수정 |
| `test` | 테스트 추가·수정 | 서비스 단위 테스트 추가 |
| `build` | 빌드 설정·의존성 | `build.gradle`, `package.json` 버전 변경 |
| `ci` | CI 설정 | GitHub Actions 워크플로 수정 |
| `revert` | 이전 커밋 되돌리기 | `revert: <원래 제목>` |

### 2.1 헷갈리는 경계

| 상황 | 기준 |
|------|------|
| 보안 취약점 때문에 의존성 버전을 올릴 때 | 엄밀히는 `build`. 취약점 조치라는 의미를 살리려면 `fix`도 허용한다 |
| `chore`와 `build` | 의존성·빌드 설정 변경이면 `build`, 스크립트·개발 툴링이면 `chore` |

---

## 3. 예시

**좋은 예**

```
chore: sync.sh 모듈 목록을 접두사 탐색으로 변경

- 하드코딩 모듈 목록 대신 atlas-flight-* 폴더 자동 탐색
- git 저장소가 아닌 폴더는 동기화 대상에서 제외
- SYNC_PREFIX로 접두사 변경 가능
```

```
chore: 스크립트 수정

컨테이너 명칭 변경
```

**나쁜 예**

```
sync.sh 고쳤습니다.

하드코딩 목록 대신 atlas-flight-* 폴더를 탐색하도록 바꾼다.
git 저장소가 아닌 폴더는 제외한다.
```

- type이 없고, 제목이 서술형이며 마침표로 끝난다
- 본문이 목록이 아닌 서술형 문장이다
