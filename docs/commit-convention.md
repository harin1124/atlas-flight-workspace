# 커밋 메시지 컨벤션

워크스페이스 메타 레포와 하위 모든 모듈(`atlas-flight-*`)에 공통으로 적용한다.

## 1. 기본 형식

```
type(module): 한글 명사형 제목

- 상세 항목 1
- 상세 항목 2
```

| 항목 | 규칙 |
|------|------|
| 제목 | `type(module): 제목`. 제목은 한글 **명사형**으로 끝낸다 (`~개발`, `~추가`, `~변경`, `~수정`, `~정정`) |
| module | 필수. 커밋하는 저장소 이름에서 `atlas-flight-` 를 뺀 값 (`auth`, `customer`, `core-lib` …). 메타 레포는 `workspace` |
| 상세 | 제목 다음 **빈 줄 정확히 1줄** 후, 모든 줄을 `- ` 로 시작하는 **개조식**으로 쓴다. "~한다", "~했습니다" 같은 서술형은 쓰지 않는다 |
| 줄 끝 | 제목·상세 모든 줄 끝에 마침표(`.`)·쉼표(`,`)를 쓰지 않는다 |
| 짧은 커밋 | 변경이 하나면 제목만으로 충분하다 |
| 식별자 | 파일명·클래스명·경로·설정 키는 원문 그대로 쓴다 |

---

## 2. type

자주 쓰는 `feat`, `fix`, `refactor`, `chore`가 위에 있고, 나머지는 해당할 때 쓴다.

| type | 용도 | 이 프로젝트 예시 |
|---|---|---|
| `feat` | 새 기능 추가 | 내 정보 조회 엔드포인트 추가 |
| `fix` | 버그 수정 | 관계 코드 컬럼 매핑 정정 |
| `refactor` | 동작 변화 없이 구조 개선 | MariaDB driver 변경 |
| `chore` | 그 밖의 잡무 (스크립트, 툴링 등) | sync.sh 수정 |
| `perf` | 성능 개선 | 쿼리 N+1 제거 |
| `style` | 포맷·공백·세미콜론 등 (로직 변화 없음) | lint 자동 정리 |
| `docs` | 문서만 변경 | `docs/*.md`, README 수정 |
| `test` | 테스트 추가·수정 | 서비스 단위 테스트 추가 |
| `build` | 빌드 설정·의존성 | `build.gradle`, `package.json` 버전 변경 |
| `ci` | CI 설정 | GitHub Actions 워크플로 수정 |
| `revert` | 이전 커밋 되돌리기 | `revert(module): <원래 제목>` |

### 2.1 헷갈리는 경계

| 상황 | 기준 |
|------|------|
| 보안 취약점 때문에 의존성 버전을 올릴 때 | 엄밀히는 `build`. 취약점 조치라는 의미를 살리려면 `fix`도 허용한다 |
| `chore`와 `build` | 의존성·빌드 설정 변경이면 `build`, 스크립트·개발 툴링이면 `chore` |

## 3. 예시

**좋은 예**

```
feat(auth): 로그인 개발

- JWT 적용
- 테스트 코드 추가
```

```
chore(workspace): sync.sh 모듈 목록을 접두사 탐색으로 변경

- 하드코딩 모듈 목록 대신 atlas-flight-* 폴더 자동 탐색
- git 저장소가 아닌 폴더는 동기화 대상에서 제외
- SYNC_PREFIX로 접두사 변경 가능
```

```
fix(customer): 관계 코드 컬럼 매핑 정정
```

**나쁜 예**

```
feat: 로그인 개발했습니다.

JWT를 적용했다.
* 테스트 코드 추가,
```

- module 이 없다
- 제목이 서술형이며 마침표로 끝난다
- 상세가 `- ` 로 시작하지 않고, 서술형이며, 줄 끝에 마침표·쉼표가 있다

## 4. 자동 검사 (commit-msg 훅)

`scripts/git-hooks/commit-msg` 가 커밋 시점에 이 규약을 검사하고, 어긋나면 사유와 함께 커밋을 거부한다. 쉘·IDE·Claude 등 커밋 경로와 무관하게 동작한다.

```bash
./scripts/install-git-hooks.sh              # 메타 레포 + 모든 atlas-flight-* 모듈에 설치 (clone 후 1회)
./scripts/install-git-hooks.sh --uninstall  # 해제
```

| 검사 | 내용 |
|------|------|
| 제목 형식 | `type(module): 제목`, type 은 2절 목록, 콜론 뒤 공백 1칸 |
| module | 현재 저장소의 origin 이름에서 `atlas-flight-` 를 뺀 값과 일치 (origin 이 없으면 폴더명 기준) |
| 한글 | 제목에 한글 포함 |
| 줄 끝 | 제목·상세 모든 줄 끝 마침표(`.`)·쉼표(`,`) 금지 |
| 어미 | 제목·상세가 `~다`, `~요` 로 끝나면 거부 (명백한 서술형만 잡는 휴리스틱) |
| 상세 | 제목 다음 빈 줄 정확히 1줄 (0줄·2줄 이상 거부), 모든 줄 `- ` 로 시작 (`Co-Authored-By:` 등 trailer 제외) |

- `Merge ...`, `Revert "..."`, `fixup!`/`squash!` 자동 메시지는 검사 제외
- 불가피한 경우 `git commit --no-verify` 로 우회
- GitHub 웹에서 만드는 머지·스쿼시 커밋은 검사 대상이 아님
