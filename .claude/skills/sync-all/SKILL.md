# 모듈 동기화 + 업데이트 요약

프로젝트 루트의 `sync.sh`를 실행하고, 실행 전후 HEAD를 비교해 모듈별로 새로 들어온 커밋을 모은 결과다.
(`sync.sh`는 이 스킬과 별개로 사람이 직접 `./sync.sh`로 실행해도 된다.)

!`./.claude/skills/sync-all/sync-report.sh`

## 정리 방법

위 결과만 근거로 아래 형식으로 짧게 보고한다. 결과에 없는 내용을 추측해 덧붙이지 않는다.

1. **한 줄 총평** — 성공/실패/건너뜀 수, 업데이트된 모듈 이름.
2. **모듈별 업데이트** — `=== 모듈별 커밋 ===`의 "새로 들어온 커밋"이 있는 모듈만, 모듈마다 1~3줄.
   - 커밋 **제목과 본문을 모두** 읽고 같은 주제끼리 묶어 "무엇이 바뀌었는지"를 기능·설정 단위로 쓴다. 커밋을 하나씩 나열하지 않는다.
   - `chore:`처럼 제목이 모호하면 본문 내용으로 판단한다. 본문도 비어 있으면 제목 그대로 짧게 쓴다.
   - `Co-Authored-By` 같은 트레일러는 무시한다.
3. **주의 필요** — 해당할 때만:
   - pull 실패(✖) 모듈과, "받지 못한 커밋"이 있으면 그 커밋들이 무엇에 관한 것인지 한 줄.
   - 건너뛴 모듈(원격 브랜치 없음 등)과 그 이유.
   - 신규·삭제된 원격 브랜치(🌱/🗑) 이름.
4. 업데이트된 모듈이 하나도 없으면 "모든 모듈 최신" 한 줄로 끝낸다.
